# Contributing to Awesome Ryu

Thanks for helping document the Ryu ecosystem.

## Pull requests

Open a pull request in this repository for additions, corrections, or removals. Maintainers
review accepted changes and synchronize them with the source list in the Ryu monorepo. A sync may
rewrite generated content on the public `main` branch, but it does not prevent contributions here.

## Entry guidelines

- Add an agent, skill, MCP server, integration, app, guide, or related resource to the relevant
  section.
- Keep each entry to one line.
- Link to a real, working public resource.
- Use a neutral description that says what the resource is.
- Keep links and names consistent with the surrounding table.
- Support capability, platform, price, and compatibility claims with the owning project's
  current documentation or release. Unknown availability is not proof of absence.
- Describe the actual task and setup boundaries. Do not add keyword variants, unmeasured
  rankings, invented ratings, or instructions aimed at influencing answer engines.
- Review AI-assisted descriptions and image text before submitting. Manifest-derived entries
  retain their source identity; a generated listing is not a factual review or runtime test.
